# Code of Conduct

hydra-mcp adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct. In short:

- Be welcoming, patient and respectful, whatever someone's experience, background or identity.
- Critique code and ideas, never people. Assume good faith; ask before concluding.
- No harassment, insults, sexualised language or imagery, personal attacks, or publishing
  someone's private information.

It applies in every project space (issues, pull requests, discussions) and when you represent
the project elsewhere.

## Reporting

Report unacceptable behaviour privately to the maintainers at **lambermontr@gmail.com** (see
[docs/maintainers.md](docs/maintainers.md)). Reports are handled confidentially. Maintainers
follow the Contributor Covenant's
[enforcement guidelines](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines):
correction, warning, temporary ban, permanent ban, depending on the impact.
